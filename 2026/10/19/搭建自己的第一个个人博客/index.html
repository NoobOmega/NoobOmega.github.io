我的学习路径

写在前面

大家好，可以说这里是我的第一篇博客吧，也可以说是我计划写的“我的学习路径”系列的第一篇

为什么突然想要写博客了呢，而且为什么系列这叫做“我的学习路径”？

这背后或许有非常复杂的原因

  • 为什么突然想要写博客了呢？

    可能是受附近人的影响，也可能是想要改变自己颓废的状态吧。逼着自己写博客去记录一下自己的学习生活，也是一种提高的方法，另外，现在AI时代，通过与AI对话的方式学习的话，AI生成的内容总是覆盖范围太大而难以回答到真正核心的问题，总是感觉少了一些“人味”，希望我手写的内容能够让大家看的不那么“力竭”。另外，能够通过自己手写的方式去产出一些东西，也算是一种对以前的大佬们的致敬吧。

  • 为什么系列这叫做“我的学习路径”？

    当我大一转专业过来的时候，非常羡慕那些拥有技术的人，但是一直不知道去哪里学习相对系统的知识，导致我大二摸索得比较痛苦吧，也没有去干一些拥有产出的事情，写这个系列也是觉得，或许能为后来的学弟学妹们提供一些指导，不要等到像我这样来到了大三才追悔莫及。

  • 文章风格：

    作者不喜欢重复造轮子，因此会在相应的地方贴上作者推荐的文档，供读者选读。在文章中只记录自己的思考和有意思的感触。

总之如此这般，还是选择写博客，刚好也能够消磨升入大三后大量的空闲时间

那么学习之路，就从自己的第一篇博客开始吧

前期准备

  • windows
  • github
  • git （推荐阅读git原理）

过程

询问gemini

一开始，也是突然突发奇想，想着搭建一个博客吧。于是很自然的去询问如何去搭建一个个人博客，AI也是很自然的给出了一大段回复，教我怎么进行基础配置。

大概如图。

但是运行完这些CLI命令后，以及按照AI的教程一步步配置完_config.yml之后，看起来博客已经可以正常运转了，但是审美我真的无法评价，是一个看起来非常古老，死板甚至毫无人味的博客，并且我对整个hexo是如何运作的毫无概念，仿佛一个死板的命令执行机器。但是如果要我不懂的都去一个一个问AI，AI给出的答案又是那么的零散，不成体系，以及无法准确契合我的情况。


但是，幸运的是，我在配置文件中看到了这个，文档，古法编程时代的产物？我抱着试试的心态点了进去。

阅读文档

英文文档(当然在hexo文档中你可以手动切换中文文档，我只是想锻炼一下我的英语能力吧)一开始确实难以阅读，不过如果你安装了“沉浸式翻译”浏览器插件以及一些市面上的词典，慢慢读总能读通的。

阅读完之后，感觉整个人对hexo的运行方式都通透了很多，hexo不过是一个将你的source文件夹中的内容根据配置文件转化为相应主题的一个“转换器”。因此，最关键的部分便只在于配置文件，source文件夹以及主题。

于是通过筛选主题并且查看相应的文档，我也成功配置了一个我喜欢的风格的博客吧。
